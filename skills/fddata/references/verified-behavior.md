# 验证依据

2026年11月10日通过已登录后台实测。数据范围为2026年9月10日至11月9日，在约与体验客户，灵感成款、自由改款和AI视频相关场景。

- 26个成功批次，302,537条记录，覆盖61天。
- 完整范围页面查询返回302,537条，与分批数据一致。
- 单批提交至实际文件保存约9.5至13.1秒，不包含筛选、查询、校验及文档整理时间。
- 17,669条成功批次约13.1秒；19,696条和35,315条尝试约60秒后结束等待，未产生文件。
- 因此采用每批15,000条以内作为初始建议。它是实测后的工作参数，不代表后台固定限制或对未来性能的保证。

配套程序于同日使用上述26批真实文件完成302,537条记录的清单构建、合并和完整解压读取核验。另用10,811条真实记录验证自定义范围、独立报告目录、秒级日期、历史报告范围补充、硬链接归档及已有文件冲突保护。Skill格式检查通过。

关键文件特征：

- 生成记录工作表范围可能标为A1:A1，实际包含大量数据；读取前重置范围。
- `id`存在重复值，完整记录不同，不能单独作为去重依据。
- 导出列没有在约状态，依赖当次页面筛选证据。
- 用户提示词与传入提示词在页面分别展示，文件只有提示词一列；不能据此声称已比较两种提示词。
- 灵感成款快速与Agent可能统一导出为灵感成款。故事版、故事版视频分别出现为故事板、故事板视频。
- 文件没有企业余额、充值流水等信息。生成失败中的上游额度提示不能证明客户的FD积分耗尽。

这些是历史观察。页面控件、列结构、筛选语义或接口表现变化时，以现场结果重新核验。Skill不携带客户原始数据或登录凭据。
