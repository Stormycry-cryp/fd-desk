# 后台操作

## 进入与筛选

复用已经连接且登录的知衣后台浏览器。用户页面被其他任务使用时，打开同地址的独立标签页；不得打断另一项任务。只查看和导出生成记录。

默认筛选的对应入口：

| 控件 | 选择 |
|---|---|
| 在约状态 | 在约、体验 |
| 生成场景 → 灵感成款 | 灵感成款-快速、灵感成款-Agent |
| 生成场景 → 服装设计 | 自由改款 |
| 生成场景 → 视频生成 | 自由创作、图生视频、首尾帧、多图参考、故事版、故事版视频、动作跟随、全能替换、实况图 |

默认场景为12项。分类名称只是切换面板，需逐项选中场景并确认。检查实际选中值，不能只依赖已选数量。灵感成款旧版是另外一个选项，只有用户明确包含旧版时才增加。

用户调整范围时，保存实际选择的`scope.json`。场景选项与导出值的对应关系需要依据页面及样本确认，不能根据名称相似自行扩大范围。

## 时间与查询

已验证的页面存在同名的开始时间、结束时间输入框：主页面输入框为只读，日期弹窗中的`input.ant-calendar-input`可编辑。使用该选择器前先查看当前DOM确认结构仍然成立；不要硬编码历史无障碍元素编号。

打开时间弹窗，填写起止时间，点击确定，再执行查询。等待新结果出现后核对日期与总数。日期输入框先更新、列表稍后才更新，长范围查询尤其要注意旧记录仍会显示。

重叠时间范围可能具有相同的最新记录时间，因此只检查首条日期不足以确认查询完成；同时观察查询状态、总数更新及其他可见结果。不能确认时保留查询未完成状态。

初始尝试每批控制在15,000条以内，按实际条数选择时间跨度。连续范围采用秒级边界，例如上一批结束于2026-11-02 11:59:59，下一批开始于12:00:00。

## 导出与文件归属

1. 打开导出报表，导出数量选择全部。
2. 弹窗和主页面可能各有一个导出报表按钮，应定位弹窗中的按钮。
3. 在点击时记录实际`Date.now()`或等价毫秒时间，连同查询日期、条数保存为运行记录。不要事后按文件编号猜测提交时间。
4. 观察导出中、完成或错误状态，同时检查下载目录。下载事件监听有可能没有返回通知，必须确认本次实际文件。
5. 使用文件创建时间、实际数据范围和行数判断归属。下载文件名的数字后缀会跳号，不能将下一编号直接视为本批文件。
6. 文件完整且内容校验通过后才提交下一批。页面仍在处理时不重复点击。

不要为了提速并发发起多个大批次。不要使用页面中前100、500、1000、3000条来覆盖同一大范围，这会截断历史数据。

## 页面核验记录

每次任务保存页面地址、提取日期与时区、实际日期范围、各状态复选框值、场景列表、其他筛选项、页面总数和结果时间证据。该记录与原始文件一起保存，避免导出列缺少在约状态导致范围无法复查。

完整范围查询过慢或明确失败时，按连续周范围分别获取页面数量。分段总数须来自重新执行的独立查询，覆盖整个目标时间范围，然后由合并程序逐段核对。
